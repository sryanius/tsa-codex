# 침묵의 기록자 자료실

모바일 게임 *The Silent Archivist* 를 혼자 편하게 하려고 만든 개인용 조회 도구입니다.
게임이 화면에 띄워 주지 않는 조건 — 퀘스트 등장에 필요한 평판, 선행 체인, 시설 업그레이드
해금 순서, 몬스터 드랍 — 을 한자리에 모아 봅니다.

## 이 저장소에 들어 있는 것

**껍데기(HTML·JS)뿐입니다.** 게임에서 추출한 데이터는 여기 없습니다.

퀘스트 원문·아이템·몬스터 데이터는 상용 게임의 저작물이라 공개 저장소에 올리지 않았습니다.
데이터는 비공개 Supabase Storage 에 두고, 로그인한 본인만 내려받습니다.
그래서 이 주소를 아는 사람이 열어도 **로그인 화면에서 멈춥니다.**

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 표지 — 평판 공식, 보물금고 원리 |
| `quests.html` | 퀘스트 색인 — 세이브 연동 |
| `codex.html` | 도감 — 탐색지·몬스터·아이템 |
| `guide.html` | 집 PC 에서 쓰는 법 |
| `tsacloud.js` | Supabase 연결 (인증·데이터·진행도) |

## 세이브 연동

세이브 파일은 **브라우저 안에서만** 복호화됩니다. 파일이 서버로 올라가지 않고,
거기서 뽑은 «퀘스트별 클리어 횟수»만 본인 계정으로 저장돼 기기 간에 동기화됩니다.

## 준비 (한 번만)

1. Supabase SQL Editor 에서 `cloud/001_tsa.sql` 실행
2. Storage → `tsa-data` 버킷에 `data.json` · `codex.json` 업로드
3. Authentication → URL Configuration 에 이 Pages 주소를 Redirect URL 로 추가

데이터를 다시 만드는 스크립트는 이 저장소에 없습니다 (APK 추출물이 필요합니다).

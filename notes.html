요구 평판은 부호에 따라 방향이 반대입니다. 양수는 «그 값 이상»이라야 뜨는 하한이고, 음수는 «그 값 이하»여야 뜨는 상한입니다. 그래서 선행 체인을 하나로 합칠 수 없어, 퀘스트 색인에서는 ▲ 한 번은 올려야 하는 평판과 ▼ 한 번은 내려가야 하는 평판을 따로 계산합니다.

평판이 오르다 멈추는 이유

퀘스트 레벨 = master.level + Min(addLevel, master.maxAddLevel) 평판 상한 = 5 × (퀘스트 레벨 − TownMaster.maxReputationLevel + 1) // 최소 5 if (평판 상한 >= 현재 평판) 현재 평판 += master.reputation // 최대 99

낮은 레벨 퀘스트를 아무리 반복해도 평판이 어느 선에서 멈추는 이유입니다. 천장이 5 단위로 올라갑니다. «상한 ≥ 현재» 일 때 더하므로 상한에 닿은 채로 한 번은 더 오릅니다(실질 최대 = 상한 + 보상). 실패했을 때 평판이 어떻게 깎이는지는 지역 §0 에 있습니다.

주점 — 용병을 뽑을 때

주점 레벨은 초빙 포인트를 바꿉니다. 화면에 별처럼 뜨는 그 숫자입니다.

포인트 = Rand(3) // 0~2 + 주점 레벨 + 성격 몫 // 무모한 0~2 · 이기적 0~1 · 나머지 0 if (RandSuccess100(10)) 포인트 += Rand(주점 레벨) // 10% 로 0 ~ 레벨−1 실제 최대 = 주점 레벨 × 2 + 3 화면의 «최대» = 주점 레벨 + 3
화면에 뜨는 «최대»가 진짜 최대가 아닙니다. 표시는 주점 레벨 + 3 인데, 무모한 지원자는 주사위가 안 터져도 주점 레벨 + 4, 10% 가 터지면 주점 레벨 × 2 + 3 까지 갑니다. 6레벨 주점이면 표시는 9인데 실제로는 15 까지 나옵니다.

포인트와 능력치는 서로 다른 주사위입니다

이 둘을 섞어 생각하면 헷갈립니다. 용병을 뽑을 때 주사위가 두 번, 서로 무관하게 굴러갑니다.

  • 능력치 8종(생명점·마나·힘·체력·지능·민첩·재주·통찰)은 종족 기준값을 흔들어 정합니다 — 주점 레벨은 영향이 없습니다.
  • 초빙 포인트(화면의 그 숫자)는 위 식이고, 주점 레벨이 그대로 더해집니다.
주점을 올려도 «민첩 7~11» 같은 범위는 안 바뀝니다. 그 범위는 종족이 정합니다 — 풋워커 남자의 민첩 기준값이 9라서 7~11 입니다. 주점 레벨이 바꾸는 것은 포인트뿐입니다.

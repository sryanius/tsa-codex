집에서 쓰는 법

회사 PC 없이, 집 컴퓨터와 폰만으로 자료실을 보고 세이브 진행도를 갱신하는 방법입니다. 파이썬도 서버도 필요 없습니다 — 세이브를 꺼낼 때만 adb 가 필요합니다.

0 클라우드 자료실 (설정하면 이게 제일 편합니다)

https://sryanius.github.io/tsa-codex/ — 어디서든 열리고, 세이브를 넣으면 다른 기기에도 자동으로 반영됩니다.

껍데기는 GitHub Pages 에 공개돼 있지만 게임 데이터는 들어 있지 않습니다. 퀘스트·도감 데이터는 비공개 Supabase Storage 에 있고, 본인 구글 계정으로 로그인해야 받습니다. 남이 주소를 알아도 로그인 화면에서 멈춥니다.

준비 — 세 단계, 한 번만

  1. SQL 실행 — Supabase 대시보드 → SQL Editor 에 cloud/001_tsa.sql 전체를 붙여넣고 Run.
    용병단의 saves·scores 는 건드리지 않습니다. tsa_progress 테이블과 tsa-data 버킷만 새로 만듭니다.
  2. 데이터 업로드 — Storage → tsa-data 버킷 → Upload 로 두 파일을 넣습니다:
    C:\claudepp ull\data.json (1.6MB) · C:\claudepp ull\codex.json (1.1MB)
  3. 로그인 주소 허용 — Authentication → URL Configuration → Redirect URLs 에 추가:
    https://sryanius.github.io/tsa-codex/**
3번을 빼먹으면 구글 로그인 후 «redirect_to is not allowed» 로 튕깁니다. 가장 흔한 실수입니다.

쓰는 법

  1. 주소를 열고 구글로 로그인 (한 번 하면 유지됩니다)
  2. 데이터가 내려오면 그때부터는 오프라인에서도 열립니다 (기기에 캐시됩니다)
  3. 세이브를 갱신하려면 3번 절차대로 Town 폴더를 받아 «세이브 폴더 열기» — 넣는 순간 클라우드에 올라가고, 폰에서 열면 그 진행도가 그대로 보입니다
세이브 파일 자체는 서버로 안 갑니다. 브라우저가 복호화하고, 거기서 뽑은 «퀘스트별 클리어 횟수»만 본인 계정으로 저장됩니다.

1 다른 방법 — 보기만 할 때는 아무것도 필요 없습니다

세 페이지 모두 인터넷 주소로 열립니다. 폰이든 집 PC든 그냥 열면 됩니다. 회사 PC의 localhost:6101 은 필요 없습니다.

자료실 표지평판 공식 · 보물금고 원리 퀘스트 색인1364건 · 세이브 연동 도감탐색지 · 몬스터 · 아이템

폰 브라우저에서 열고 홈 화면에 추가하면 아이콘이 생겨 앱처럼 씁니다.

진행도는 어떻게 되나요? 지금 색인에 박혀 있는 «클리어 1102건»은 2026‑08‑26 시점 스냅샷입니다. 게임을 더 하면 낡습니다. 최신으로 맞추려면 아래 2·3번을 하시면 됩니다.

2 집 PC 준비 — 딱 한 번

adb 설치

Windows 라면 PowerShell 에서:

winget install --id Google.PlatformTools -e

winget 이 없으면 platform-tools 를 받아 압축만 풀어도 됩니다. 설치 후 터미널을 새로 열어야 adb 명령이 잡힙니다.

adb version   # 버전이 나오면 성공
파이썬·서버·스크립트는 필요 없습니다. 복호화는 브라우저가 합니다. 회사 PC 의 C:\claude\app 폴더를 옮겨올 필요도 없습니다.

3 세이브 꺼내서 반영하기 — 게임하고 나서 반복

3‑1. 폰을 무선으로 연결

  1. 폰: 설정 → 개발자 옵션 → 무선 디버깅 켜기 (PC와 같은 Wi‑Fi)
  2. «페어링 코드로 기기 페어링» 을 누르면 6자리 코드와 IP:포트가 뜹니다
  3. PC에서 (팝업의 IP·포트·코드를 그대로):
adb pair 192.168.0.214:41234 683465

성공하면 무선 디버깅 메인 화면의 IP:포트(페어링 팝업의 것과 다릅니다)로 접속합니다:

adb connect 192.168.0.214:38099
adb devices        # device 라고 뜨면 연결됨
폰 IP가 192.168.x.x 가 아니면(예: 10.x.x.x) VPN·광고차단 앱이 켜져 있는 것입니다. 끄고 다시 여세요.

3‑2. 세이브 내려받기

adb pull /sdcard/Android/data/com.TownSoft.soulsofadventure/files/Town

현재 폴더에 Town 폴더가 생기고 .data 파일 수십 개가 들어옵니다. 퀘스트 진행도는 이 폴더에만 있습니다 — 다른 폴더는 안 받아도 됩니다.

3‑3. 페이지에 넣기

  1. 퀘스트 색인 을 PC 브라우저로 엽니다
  2. 상단 세이브 줄에서 «세이브 폴더 열기» → 방금 받은 Town 폴더 선택
  3. «세이브 반영 완료 — 파일 28개 · 퀘스트 1204건» 이 뜨면 끝
복호화는 브라우저 안에서만 일어납니다. 파일은 어디로도 업로드되지 않고, 결과는 그 브라우저의 저장소에만 남습니다. 다른 기기에서 보려면 그 기기에서 다시 넣어야 합니다.

폴더 선택이 안 되는 브라우저면 «파일로 고르기» 로 .data 파일을 전부 선택해도 됩니다.

4 되는 것과 안 되는 것

하고 싶은 것집에서비고
퀘스트·도감 보기됨주소만 열면 끝. 폰·PC 아무거나
세이브 진행도 갱신됨집 PC + adb 필요
폰만으로 세이브 갱신안 됨안드로이드가 다른 앱의 Android/data 접근을 막습니다
게임 업데이트 후 데이터 갱신안 됨APK 재추출이 필요합니다 — 회사 PC 로 돌아온 뒤에
게임이 업데이트되면 퀘스트·아이템 데이터가 낡습니다. 세이브 연동은 계속 되지만 새로 추가된 퀘스트는 목록에 없습니다. 그건 APK 를 다시 뜯어야 해서 집에서는 못 합니다.

5 막혔을 때

증상원인 · 해결
adb devices 가 비어 있음 무선 디버깅이 꺼졌거나 페어링이 만료됨. 폰에서 껐다 켜고 페어링부터 다시
페어링은 되는데 connect 실패 페어링 팝업의 포트와 메인 화면의 포트가 다릅니다. 접속에는 메인 화면 포트를 쓰세요
폰 IP가 10.x.x.xVPN·광고차단 앱을 끄세요
«magic 불일치» 오류 .data 가 아닌 파일이 섞였거나 게임 저장 포맷이 바뀐 것
넣었는데 숫자가 그대로 Town 폴더가 맞는지 확인. 다른 폴더에는 퀘스트 기록이 없습니다

6 회사 PC 에 있는 것 (참고)

C:\claude\app 에 원본과 스크립트가 있습니다. 집에서는 필요 없지만 나중을 위해:

경로내용

세이브 암호는 78nA1_IJKf_ZOUn1I8_KeM0, 형식은 [16]IV [32]salt [16]MD5 [..]AES‑256‑CBC, 키는 PBKDF2‑SHA1(암호, salt, 50회, 32바이트) 입니다. 게임이 업데이트되면 이 값이 바뀔 수 있습니다.
